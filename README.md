# 三国杀 · 身份局

纯 HTML/CSS/JavaScript 实现的单机三国杀，无需安装或构建。

**在线试玩：https://liyucheng1997.github.io/401_game-sanguosha/**

## 运行

直接双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge）。

也可以起一个本地静态服务器：

```bash
python -m http.server 8765
```

然后访问 http://localhost:8765 。

## 内容

- **身份局** 4–8 人：主公 / 忠臣 / 反贼 / 内奸，含击杀奖惩与胜负判定
- **完整牌堆 160 张**：标准版 104 + EX 4 + 军争篇 52（火杀、雷杀、酒、铁索连环、火攻、兵粮寸断、藤甲、白银狮子、古锭刀、朱雀羽扇、骅骝等）
- **51 名武将**：标准版 25 名 + 风火林山共 26 名，含主公技、限定技、觉醒技
- **四档 AI 难度**
  - 简单：随机性大、常失误、不推理身份
  - 普通：根据行为推理身份，偶有失误
  - 困难：身份推理（行为印象 + 阵亡信息排除法）、内奸平衡策略、局势评估、酒杀连招、无懈博弈、改判、留牌
  - 地狱：在困难基础上知晓所有人的真实身份
- **特效**：Canvas 粒子（刀光、火焰、雷电、万箭、冲击波、治疗、闪避护盾、阵亡灰烬）、指向箭头、飞牌动画、技能书法横幅、判定盖章、震屏
- **声音**（顶栏可分别开关 音效 / 配音 / 音乐）
  - 音效：Kenney、OpenGameArt 的 CC0 采样（出牌、洗牌、刀剑、格挡、受击、钟声……），火焰/雷电等叠加程序合成层
  - 配音：本机 F5-TTS 合成，每个技能两句台词、每位武将一句阵亡台词，外加男女声出牌喊话（共 253 条）
  - 背景乐：程序生成的五声音阶古筝拨弦，配音时自动压低
  - 素材来源见 [assets/CREDITS.md](assets/CREDITS.md)

## 操作

- 点手牌选中 → 点发光的角色选目标 → 「确定」；**双击**手牌可快速使用
- 转化技（武圣、龙胆、倾国、急救……）直接点可转化的牌；两张牌的转化（丈八蛇矛、乱击）先点技能按钮
- 右键取消选择；Enter 确定、Esc 取消、空格结束出牌
- 顶栏：托管（AI 代打）、战报、音效、速度、菜单
- 悬停在牌 / 角色 / 技能上查看说明

## 目录

```
index.html
css/style.css
js/util.js       卡牌模型、工具
js/cards.js      160 张牌定义与效果
js/engine.js     回合流程、结算、伤害、濒死、判定、无懈连锁
js/skills.js     武将技能与装备技能
js/generals.js   武将列表
js/ai.js         AI（身份推断、出牌规划、响应决策）
js/fx.js         粒子特效与合成音效
js/ui.js         界面渲染、动画、玩家交互
js/main.js       菜单、图鉴、对局生命周期
tools/sim.js     无界面 AI 对战回归测试
```

## 测试

```bash
node tools/sim.js 2000 hard
```

批量运行 AI 对局，检查异常与牌数守恒（任意时刻 160 张），并输出胜率统计。

## 重新生成配音

改 `tools/voice_script.js` 里的台词或音色后：

```bash
node tools/voice_script.js
```

```bash
"F:\我的编程项目\123_AI视频自动化\tools\f5-tts-env\python.exe" tools/gen_voice.py
```

```bash
node tools/build_voice_index.js
```

`gen_voice.py` 只重录改动过的台词，每条用 Whisper 识别校验，读错会自动换种子重试。
